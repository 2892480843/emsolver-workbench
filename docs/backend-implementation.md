# 应用服务实现与边界

验证环境：macOS / Darwin，Python 3.12，独立 `.venv-emsolver`。服务模块为 `emsolver.service`、`store`、`api`、`worker`，所有输入与配置复用数值及配置模块。

## 可运行路径

- `Service(root, start_runner=True)` 管理 SQLite 元数据和单个 FIFO（先进先出）执行队列。`close()` 回收工作进程、后台线程和数据库连接。
- 每次运行创建独立 Python 子进程，限制计算线程。父进程每约 0.1 秒采样自身工作进程及后代的常驻内存、目录大小和墙钟时间，超限回收整棵进程树。短时尖峰可能落在采样间隔内，不能将采样峰值当成连续精确测量。
- 数值产物位于 `runs/<job>/artifacts/`；控制文件和服务端事件位于任务目录。数值核心仅接受授权矩阵路径、冻结配置和独立输出目录。
- 新实例取得文件锁后核验遗留工作进程的命令行及创建时间，回收匹配的进程树，并将遗留执行记录终结为 `WORKER_LOST`。没有伪造的精确断点续算；重试新建关联任务。
- 幂等键（网络重试使用的唯一请求标识）通过 SQLite 即时写事务校验请求摘要。相同键及请求返回同一任务，不同请求返回冲突。
- 计划提交前重验矩阵文件哈希及运行能力。归档项目或矩阵禁止新建计划及提交，既有任务和产物继续保留引用。

## 导入、下载和复现

本地导入只接受 `EMSOLVER_IMPORT_ROOTS` 指定的根目录；默认允许当前工作目录及数据目录的 `inbox`。导入先复制私有快照，再交数值模块安全验证，不接受对象反序列化。上传文件名不能包含路径分隔符。只保存校验通过的记录，并按内容哈希复用只读输入文件。

结果下载只接受显式文件白名单。报告经统一报告模块转义；公开复现包默认不包含输入矩阵。能力接口移除数值线程库返回的本地文件路径。

私有备份包含 SQLite 一致快照、输入、运行目录及报告，逐个文件流式写入并计算实际写入字节的校验和。恢复必须使用新空目录，拒绝路径穿越、符号链接、重复成员、超大展开体积及校验和错误，检查实体引用并重建已知数据库表结构。矩阵路径重新绑定到新实例目录。API 恢复入口只提供服务端生成的实例标识，不接受任意恢复路径；恢复实例不会自动启动。

## API 与认证

`create_app(root=None, start_runner=True)` 在应用生命周期中创建和关闭服务，导入模块不创建数据目录或启动线程。`/api/v1` 列表直接返回数组，错误为 `{error:{code,message}}`。

默认离线单用户。设置 `EMSOLVER_API_TOKEN` 后，全部 `/api/` 路径都要求 Bearer 令牌。共享令牌不能区分个人或项目角色；当前没有项目成员角色权限、账号服务或操作系统文件沙箱。工作进程不接收参考答案路径，但仍继承本机用户的文件读取权限，不能宣称已实现操作系统级参考隔离。

## v0.3实验领域边界

实验规格与预算、组合展开、冻结完整性校验、原子提交和分组统计由`experiments.py`负责。`Service`保留既有外观接口，复用资产、单作业预检及队列提交能力。新冻结方案以`experiment_plans`实体保存，不修改schema2；批次继续使用`benchmarks`，任务入库即记录组合与重复编号。

实验先冻结再提交；任何配置、能力或队列检查失败会回滚整批任务与事件。幂等请求摘要包含实验成员关系，防止普通任务占用实验重试键。提交与恢复共用冻结规格及配置交叉校验；恢复额外核对每组、每次重复的唯一任务和双向关联。

建议校验由`advice.py`保护，只接受明确允许的求解参数路径。输入、目标、验收和资源全部保持原值，修改生成新配置并保存差异与来源摘要。

## 补充结果与维护接口

- `PATCH /matrices/{id}` 版本化登记来源 URL、许可证、单位及频率映射；上传也可通过 `metadata` JSON 表单登记。计划冻结该元数据，历史作业不因之后修改而改变物理解释。
- `GET /jobs/{id}/results` 只在明确声明 `lambda=omega_squared` 后提供频率换算。单位必须为 `s^-2`、`1/s^2` 或 `rad^2/s^2` 才输出 Hz；负特征值或未知单位返回 `null`。
- `POST /jobs/{id}/export` 按零起始列号导出所选模式，保留选择顺序、原列号和复数值；内存、磁盘及所选列数均有限额。支持 NumPy `.npz` 和含 SciPy 稀疏向量文件的 ZIP。
- `GET /jobs/{id}/vectors/{mode}` 只采样代数向量的分量，最多 512 点。不将没有几何或自由度映射的数组伪装成物理电磁场。
- `POST /cleanup` 默认为 `dry_run: true`。只清理超过 24 小时的未引用输入、临时文件和孤立任务目录，保留所有已登记矩阵和任务引用。
- `POST /reports` 可选择单个 `job_id` 或 `benchmark_id`，两者必须且只能提供一个。批次报告保留全部作业，包括失败、取消和未完成行。
- 可比性检查要求同输入、目标、精度、资源、运行环境、主机硬件标识和已认证成功状态，满足后才基于实际工作进程墙钟时间计算加速比。
