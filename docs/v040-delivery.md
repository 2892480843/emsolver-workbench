# v0.4.0 软件交付记录

本轮落实原PRD的软件工作流，保持66条原文和验收边界。正式本机服务已升级至 `http://127.0.0.1:8000/`。是否满足赛事指定硬件、合法工业数据和全部数值认证要求，需要分别核验，不能用源码材料检查替代。

## 软件与架构

- 模块化单体继续使用SQLite schema2；项目治理、异步导入、建议效果、运维、结果回收、进程接管、独立复验、冻结协议分别分模块。存储投影可重建，冻结实验不随新默认参数被重写。
- 提供实际块位移反演和Jacobi–Davidson投影修正，包含有界重启、原问题残差检查、软锁定、FP32修正及FP64复验/提升、Jacobi预处理、反馈位移和子空间热启动。结构对角路径明确记录实际算法，未执行的迭代不记为已执行。
- 实名身份与项目权限覆盖业务接口；单独运维角色只能访问脱敏资源统计和配额，默认不获得业务下载或完整备份权限。离线单用户仍是显式本地所有者。
- 备份为一致快照，忙碌求解/导入时拒绝；缺文件恢复只能显式降级。恢复已发布结果时重新在独立有界进程验证原问题，不信任缓存的“通过”标记。
- 规范事件事务提交与字节游标一致；次要观测有界且可关闭。检查点用于创建新任务热启动，不宣称精确续算。回收仅处理明确取消保留且过期的终态结果，并保留规范历史。
- 浏览器已实际操作项目策略、异步上传、预检、复数求解、收敛曲线、检查点、规则解释、建议派生运行与效果关联、运维配额保存。

## 条件边界与运行

逐条状态、原始条款及证据见 [PRD验收登记](prd-acceptance.md)。一般稀疏目标谱完整性、器件自由度/频率解释、获许可本地模型、正式工业数据及独立参考、原生指定硬件与MPI/GPU/SLEPc仍按实际条件记录。没有这些条件时软件显示未认证、不可用或明确拒绝；不生成虚假场图、模型回答或加速成绩。

macOS离线包解压后运行 `./install.sh`，默认监听本机8000端口；已有服务占用时使用 `EMSOLVER_PORT=8002 ./install.sh`。在该离线目录以 `.venv/bin/python scripts/verify_offline_instance.py --output proof.json` 可在新临时数据目录重跑验收。该命令不覆盖已有数据，证据文件必须使用新名称。

源码包、macOS离线包与Linux镜像的最终文件大小、校验值、平台和来源在 `artifacts/RELEASE-0.4.0.json` 记录。私有数据、`.env`、原始赛题PDF/DOCX、研究矩阵及旧版本产物未纳入公开包。保留旧包供追溯，不覆盖其校验值。构建、角色配置和禁网命令见 [部署说明](deployment-and-governance.md)。
