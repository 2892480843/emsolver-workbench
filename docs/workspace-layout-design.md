# 工作区布局设计与实施计划

## 目标

在既有论文排版风上优化操作效率：首屏能看到数据与入口，长表单不会遮蔽常用工作，数据图表获得足够宽度。保留白纸、衬线字体、编号、三线表和蓝色链接；工作区可以宽于阅读段落，说明文字仍限制为约72ch。

## 布局决策

采用左侧分组导航、紧凑居中文档头、按工作场景分栏的结构。纯文章单列适合阅读但操作路径过长；所有页面强制多栏会挤压长表和表单；因此使用页面语义控制布局，窄屏统一退化为单列。

| 区域 | 设计 |
| --- | --- |
| 导航 | 全部13项保留，分为实验与计算、分析与验证、系统与交付；桌面缩减重复目录说明与间距，手机保留抽屉及关闭按钮 |
| 页头 | 标题、身份、版本与摘要保持居中，减少上下留白；项目范围和页面操作位置一致 |
| 总览 | 四项指标横排，流程与环境并列，近期任务在项目管理之前 |
| 矩阵 | 桌面资产目录与诊断详情双栏，宽图与长指纹留在详情中 |
| 配置 | 桌面主表单与执行计划双栏，长证据正常滚动，避免整个高侧栏固定造成阅读遮挡 |
| 结果 | 验证状态与指标在前，图表并列，模式数据与证据表格全宽 |
| 工业 | 大屏档案目录与选中档案双栏，创建档案在后；较小屏幕单列 |
| 响应式 | 1280/1100/900/600分级，手机单列、表内横向滚动；正文、控件和状态语义保持一致 |
