## 工作区分工

数值代理负责 `emsolver/numerics/`、数值专项测试及恢复数值状态；工程代理负责新增工程模块/路由/显示组件；后端代理负责新增SLEPc驱动、构建配方与测试。主代理负责共享Service/API/配置集成、模型/数据接入、总体回归及发布。跨模块改动先通知对应所有者，不能覆盖其他代理整文件。
