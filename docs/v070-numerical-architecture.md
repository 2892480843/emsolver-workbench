# v0.7 数值架构与验收边界

本次扩展候选求解与独立验证两条调用链，保留模块化单体服务、SQLite schema 2及独立工作进程。历史输入、冻结配置、任务、检查和旧发布包保持不变。

## 候选求解

`ScipyBackend → solve_correction → BudgetedILU → SciPy spilu/GMRES`。

ILU（不完全LU分解，用有限的稀疏因子近似求逆）策略标识为`ilu_budgeted_v1`，只有显式选择CPU双精度的JD（雅可比–戴维森，迭代修正特征向量）修正方程才能启用。固定丢弃阈值`1e-3`、填充参数`2`、`basic,area`和`COLAMD`排序，不按输入名称改变策略。一次构建、跨修正方程复用，记录构建次数、因子非零项数、应用次数与耗时。

预处理工作位移为归一化目标加双精度平方根精度的范数保护量。它只改变近似逆；原矩阵、目标位移与最终验收精度保持原配置。GMRES的返回码不能替代实际修正方程残差，最终向量仍对原始未重排矩阵复验。分解失败产生结构化事件，禁止隐式重试或改参数。

分解前预检矩阵、稀疏格式转换、分别估算的L/U、符号／面板／求解工作区和向量缓冲；同时检查当前进程内存余量。估计是保守规划情景，填充参数不构成实际内存峰值上界。外层进程树监控在原生分解调用期间继续执行。读取`factor.nnz`，不导出可能复制大量数据的`factor.L/U`。

界面由后端能力决定能否选择ILU。显式选择时切换到双精度；GPU与其他算法的切换清除不兼容组合；导入非法组合显示错误并禁止提交。配置默认值不新增字段，原冻结配置的内容哈希不变。

## 独立验证

`原始输入 → 原残差／正交性 → 结构证据或有界精确消元 → 有界分离圆盘计数`。

新计数方法使用Gershgorin圆盘（用每行对角和非对角项的范围约束全部特征值）。原始IEEE浮点数被解释成精确二进制有理数；复数半径使用`|实部|+|虚部|`的保守放大。只有目标内外圆盘集合能严格分开，才推导独立数量。重叠、预算不足或候选覆盖无法证明时返回`UNVERIFIED`。

最近k的验证窗口由输入圆盘独立选取，不能由候选答案反推；区间模式采用左闭右开语义。数量之外，还检查原始稀疏乘积得到的残差包围、候选分组重数和子空间覆盖，防止重复方向或重复特征值冒充完整结果。算法不调用候选特征值求解器、浮点LU或完整稠密转换。

默认上限为100万阶、3000万非零元、16模式、200万向量项、500万算术操作、5秒；另有分数位数与计数次数上限。独立工作进程仍受最多2GiB／30秒资源保护。该方法仅支持满足分离条件的矩阵，不能替代任意大型不定矩阵的通用惯性证明。

结构分类改成每批最多65536个非零项的索引检查，避免把完整行索引扩展到所有非零项。空行按CSR行指针正确映射；该改动不改变矩阵内容。

## 数据结构

- 既有`solver.linear.preconditioner`字符串增加一个实现值，其他配置字段与默认值保持不变。
- `strategy.linear_solver.preconditioner_policy`记录固定策略；`metrics`追加实际构建／应用计数及耗时；失败事件包含阶段、原因枚举和尝试次数。
- `validation`追加独立计数来源、算术预算／统计、严格验证窗口、组重数与覆盖证据。未认证时保留明确拒绝原因。
- 不增加业务表，不迁移或覆盖旧任务，历史产物继续按自身版本解释。

## 适用范围

100003阶合成分离谱测试用于验证大规模证明路径，不构成真实微波器件验收。公开原矩阵的全部实验应分别记录预检拒绝、分解失败、预算、源码与输入哈希；成功的教学或合成实验不能覆盖这些失败。
