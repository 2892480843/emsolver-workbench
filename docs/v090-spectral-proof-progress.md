## 已完成的严格计数部件

[双移位惯性夹逼](v090-count-reference-options.md) 已有独立精确因子验证原型。对端点 `s`，分别提供 `A-(s+eta)I` 与 `A-(s-eta)I` 的因子，独立重算其完整原问题残差上界；上界小于 `eta`、两边惯性相同且没有零根，才证明端点计数。原型不依赖提供方声称的残差或惯性。

[记录式 LDL 误差上界](v090-recorded-ldl-bound.md) 则在开放的 SuiteSparse 标量分解旁外舍入记录误差，避免事后再做完整因子乘积。独立审查已修复请求有理移位到 binary64 转换的缺陷，记录在 `docs/evidence/v090-recorded-ldl-independent-review.json`。研究数据包含圆盘跨零、仍能严格证明惯性的连通 257 / 2049 阶矩阵。

这些部件的本机小型数学链路与反例已经验证，剩余阻力很具体：完整 GSM 的数值主元稳定性、1858 亿次标量运算、显式因子驻留与转换，以及能够保持严格误差界的快速分块实现。MUMPS 已有的浮点主元整数不能自动填这条严格误差链。

## 严格二范数候选包围部件

现有精确认证曾使用“残差分量绝对值之和 / 向量最大分量”来包围候选值。它严谨但可能比“残差二范数 / 向量二范数”保守约 `n` 倍；二范数就是把全部分量平方相加后开方所得到的长度。

本轮新增的 `residual_norm_bounds.c/.py` 研究部件按原始稀疏行计算乘积。每次 `fma`（融合乘加，只舍入一次）都把一个完整向上浮点间距加入误差界；再用有缩放的平方和、平方根和向外舍入得到 `residual_norm2_upper`、`vector_norm2_lower`。两者的精确有理比值能用于厄密矩阵候选的严格谱包含区间。

普通 Python 包装器仍硬限制 4096 阶 / 200000 输入项，不因为后续工业试验而直接放开。实数 / 复数、混合实复输入、极端整体尺度、32 / 64 位图索引一致性与原矩阵精确对称检查都以独立高斯有理数平方和核对。256 阶固定案例中，新包围进入既有 `value_fidelity_budget`，旧的保守包围超过同一预算；**数学阈值未放宽**。

这一部件只证明候选附近至少有一个原问题特征值。若两个严格包含区间不相交，可证明至少存在两个不同特征值；仍不知道区间之间或更靠近移位的位置是否还遗漏了别的根。它不能替代前面的全局谱计数、重数和候选组子空间证明。

## 完整 GSM 原矩阵的严格候选包围

独立数学审查后，已对生产任务 `j_b29d2f56d06d4e829e128c553dd1b493` 的两个候选执行一次预先冻结的原矩阵试验。它直接只读映射原始 `float64` 系数与 `int32` 图，重新逐项核对精确实对称、稀疏结构和有限性；未进行系数归一化、矩阵剪裁、特征值求解或数值因子分解。

中心取自本次冻结的生产输出，严格半径与端点以 `result.json` 的整数分子 / 分母为准，表中小数仅供阅读。**两个区间不相交，因此完整原矩阵至少有两个不同的特征值，分别落在这两个区间内。** 两个半径均满足原有 `value_fidelity_budget`，没有修改精度阈值。

固定工业配置的上限为 1000000 阶、30000000 项、2 个候选、2000000 个向量分量；普通小型 Python 包装器的 4096 阶上限保持不变。监督总耗时 0.963 秒，进程树观察到的内存峰值 312197120 字节，约 298 MiB。此处是每 20 ms 采样的 **512 MiB RSS 软边界**和 30 秒墙钟监督，不能称为内核硬内存沙箱。原矩阵、候选向量、执行源码与本机库摘要前后全部一致。

证据保存在 `artifacts/v090-count-reference-research/gsm-candidate-enclosures-v1/{protocol,result,supervisor}.json`。独立审查记录是 `docs/evidence/v090-residual-norm-independent-review.json`：66 个新增独立精确算术案例与本部件 28 项共 94 项通过，包含实复四组合、独立极端尺度与最小非零浮点数。最终把三个本子任务原型与两个独立审查文件一起执行，**去重后的 198 项测试全部通过，耗时 2.09 秒**，日志为 `artifacts/v090-count-reference-research/final-combined-tests.log`；独立审查的 94 项是其中子集，不能再次累加。

**该结果没有证明最近 `k` 目标完整性、各区间内的重数、候选组子空间、缺失根不存在、参考机构来源或物理意义。** 冻结结果明确保留 `target_certification=UNVERIFIED`、`missing_modes_proved_absent=false` 和 `reference_provenance_attested=false`。本研究未接入生产认证决策。
