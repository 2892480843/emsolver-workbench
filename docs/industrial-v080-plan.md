# v0.8 工业求解继续实施计划

**目标：** 修复已有通用求解路径的稳定性和过早停止问题，以独立测试验证后再冻结公开工业实验。既有v0.7源代码、任务、协议和发布包均保留。

**架构：** 预处理器仍是修正方程的可替换组件，任何均衡或补偿只能作用于近似逆。外层停止控制区分“数值有效候选”和“值得提交精确认证的精度提示”，最终认证仍独立使用原输入。不存在放宽原残差或将浮点惯性冒充严格证明的路径。

环境已确认：macOS ARM64，16GiB物理内存；仅使用本机与合法公开资源。本轮继续现有授权任务，不新增外部发布或报名动作。

## 路线取舍

| 路线 | 用途与边界 |
|---|---|
| 显式行列均衡／补偿的独立预处理策略 | 优先在与工业矩阵无关的实／复不定合成集合复现和修复因子失效；同时检查GMRES原方程残差。仅构建成功不足以接受策略。 |
| 外层精度继续迭代 | 当请求完整认证时，依据认证器已有值精度上限给出更严格的浮点停止提示。该提示不是认证。有限预算耗尽保留此前数值有效候选和PARTIAL状态。 |
| 加权圆盘或验证分解 | 先确认数学可行范围与资源；不能建立严格证据时继续UNVERIFIED，不强行增加假通过路径。 |
