# 部署、项目治理与运行边界

当前服务保留离线单用户模式，也支持实名令牌与项目角色。角色只约束 HTTP API（应用程序接口）访问；拥有数据目录操作系统权限的人仍能读取本机文件。不能把项目权限当作文件沙箱。

## 身份配置

设置 `EMSOLVER_IDENTITIES_FILE` 指向 UTF-8 JSON 文件，权限建议 `0600`。内容为 `{"users":[{"subject":"owner","token_sha256":"…64位小写十六进制…","global_admin":true}]}`。至少一名全局管理员，每个主体和令牌哈希必须唯一。用高熵随机令牌计算 SHA-256，只把哈希写入文件，浏览器填写原始令牌。配置错误时接口返回503，不回退为匿名管理员；配置文件生效时不接受共享令牌模式。

`EMSOLVER_API_TOKEN` 提供兼容的单一所有者模式；未配置两种身份且只在回环地址运行时，显示 `local-user`。对外绑定必须配置其中一种身份模式。令牌不写入元数据、审计或计算子进程环境。

项目成员角色为 viewer（查看）、analyst（导入与计算）和 admin（项目策略及成员管理）。全局管理员负责工作区备份、回收和监控。项目外资源请求拒绝并记录主体及对象，审计不记录令牌。切换浏览器令牌会重载并清空旧身份的应用缓存。

## 项目策略与存储模型

项目可配置存储上限、排队上限、优先级及保留天数。默认4096GiB、100排队、优先级0、30天，以兼容旧离线数据。队列先按显式优先级排序，再按单调提交序号排序；当前并发求解进程为1。导入另有受限验证进程，不进入求解队列。

`project_storage` 是可重建的存储投影，记录项目内按哈希去重的输入字节和已结束运行输出字节。注册输入及结束任务时在同一数据库事务内更新。活跃任务按冻结的输出硬上限预留空间，提前拒绝明显超配。逻辑配额不等于磁盘可用量；计算期间仍有进程树内存、时限与输出目录的守卫。Linux 隔离脚本另使用容器硬上限。

新增运行默认 `retained=true`，旧记录缺少该字段也视为保留。项目管理员用 `PATCH /api/v1/jobs/{id}/retention` 显式取消保留后，过期结果才可进入回收计划。`POST /api/v1/lifecycle` 的 `dry_run=true` 只预览；`false` 执行。工作区清理界面合并展示临时文件和过期产物。回收为显式维护操作，不隐式删除刚到期的数据；保留输入、配置、清单、历史验证与规范事件。回收失败有隔离暂存及回滚机制，未真正释放的物理空间单独报告。

## 异步导入

`POST /api/v1/imports` 分块写入私有暂存文件，独立验证进程校验结构、哈希和有限值；只有成功后才能注册资产。支持排队及执行中取消，最长120秒、最大1GiB输入和2GiB进程树内存。角色在提交及注册时复验；上传成功不代表矩阵已通过诊断。旧同步矩阵接口同样分块接收，但没有导入任务取消能力；界面使用异步接口。

## 备份与恢复

备份为含用户身份和私有数据的受保护归档，只向全局管理员开放。恢复只允许新空目录，核对归档成员、文件哈希、数据库完整性、引用和不可变实验关系；重新构建索引及存储投影，不导入备份里的数据库触发器或视图。临时导入文件不进入备份，恢复后未完成导入明确失败，不继续使用旧绝对路径或旧权限上下文。

备份先恢复已有回收隔离日志，再持有 SQLite 写事务进行一致快照。运行中、验证中或取消中的求解，以及运行中或取消中的导入，返回 `BACKUP_BUSY`，待其结束后重试；不能将忙碌时段宣称为热备份。未能恢复的隔离日志阻断备份，避免导出已移走而未归档的文件。

默认缺失文件即拒绝恢复。显式 `allow_missing=true` 可将缺失大文件的备份恢复为降级实例：输入显示 `MISSING`，相关任务产物显示缺失且无法新建计算；历史状态不改为通过。损坏的现存文件仍拒绝，不以降级选项绕过哈希校验。

## Linux 参考隔离与离线复现

`Dockerfile.solver` 只复制求解源码，不复制测试、数据或参考。`scripts/run_isolated.py` 只挂载具体输入、配置和候选输出，禁网、只读根文件系统、非特权用户、删除额外能力、禁止提权并设置内存/CPU/PID上限。访问探针使用相同挂载与隔离配置检查参考文件及 Docker 控制接口不可读。实际求解命令不接收参考路径；参考评测只在容器退出后由宿主评测器执行。

已实测的 Linux 容器为 amd64，运行在 macOS ARM64 的 Docker 虚拟化/模拟环境。它支持 Linux 功能与隔离的结论，不能替代比赛指定硬件的原生性能成绩。依赖镜像构建与下载需要网络；准备后可 `docker save/load` 在禁网环境运行。平台与镜像摘要必须随交付记录保存。

联网准备与禁网运行分开执行。构建 `Dockerfile.dependencies` 仅用于准备锁定的发行依赖；`Dockerfile.runtime` 使用本地项目 wheel 和已构建界面，不执行网络安装：

```sh
docker build --platform linux/amd64 -f Dockerfile.dependencies -t emsolver-dependencies:py313 .
python3 -m pip wheel --no-deps . -w build/runtime-wheel
docker build --network none --platform linux/amd64 -f Dockerfile.runtime -t emsolver-runtime:0.4.0 .
docker run --rm --network none --entrypoint python emsolver-runtime:0.4.0 /app/scripts/verify_offline_instance.py --output /tmp/proof.json
```

独立验收脚本仅请求容器内回环地址，启动全新实例，核对实际界面资源、求解、原问题复验、报告、公开包成员及哈希、备份完整性，再恢复到新目录并创建新运行。它不依赖源码工作目录或旧虚拟环境。Linux 的 `--network none` 是操作系统级断网证明；macOS 本机的 `--no-index` 安装只证明未使用包索引，不能冒充操作系统断网。

macOS 离线包以 `python-version.txt` 记录其 Python 主次版本，`install.sh` 默认选择相应 `python3.12`；可用 `EMSOLVER_PYTHON` 指定兼容解释器，版本不匹配即拒绝。不能拿 macOS arm64 的 wheels 直接安装到 Linux、Windows 或不兼容 Python。新版本应新建 wheel 目录，避免混入旧项目 wheel。

`GET /api/v1/metrics` 向全局管理员提供无项目/用户标签的 OpenMetrics 指标。次要观测缓冲有界，外部导出器失效不阻断计算；规范状态、审计和独立验证始终先持久化。详见 operations-completion.md 的配对开销实验边界。
