# 有界一般稀疏谱认证

`emsolver.numerics.certification` 为非三对角厄密矩阵增加独立认证路径。厄密矩阵是复数情况下与自身共轭转置相同的矩阵，其特征值均为实数。这里的“精确”指对实际输入中保存的 IEEE 浮点数所代表的有理数精确计算，不宣称输入本身没有测量或建模误差。

候选求解器仍使用原有浮点算法。认证器重新读取原矩阵与候选向量，完全不调用 `eigsh/eigs/eigh/eigvalsh`，不读取候选侧参考答案，不把多次迭代结果一致作为谱计数。原始矩阵及移位矩阵始终用稀疏字典表示，不调用 `toarray/todense`。

## 独立计数

惯性是矩阵正、负、零特征值的数量。对原矩阵 `A` 和精确有理端点 `s`，计算 `A-sI` 的惯性，负数部分即严格小于 `s` 的原特征值数量；零数部分给出端点处的精确重数。因此半开区间 `[lower, upper)` 的数量等于两个端点的严格小于计数之差，不通过人为微调端点处理零主元。

消元采用精确合同变换，即同时改变矩阵的行、列基；这保持惯性。非零实对角使用一阶主元。若剩余对角全为零，任一非零复数非对角元 `z` 提供 `[[0,z],[conj(z),0]]` 二阶主元，其行列式为 `-|z|²`，必有一正一负。对应 Schur 补也以有理数精确计算。全零剩余块贡献完整零特征值重数。实现不把“小数值”视为零；仅精确等于零时删除稀疏项。

## 候选与子空间证明

对候选值 `theta`、候选向量 `x`，在原单位中精确计算 `r=A*x-theta*x`。令 `R` 为残差各分量实部、虚部绝对值之和，`L` 为向量所有实部、虚部绝对值的最大值。因为 `||r||₂<=R` 且 `||x||₂>=L`，厄密残差界保证 `[theta-R/L, theta+R/L]` 至少包含一个真实特征值。

认证器将相交包含区间合为一组，随后执行以下独立检查：

1. 每组闭区间的精确惯性计数必须等于候选列数。
2. 在组外建立一圈经独立计数确认没有其他特征值的区间，取得每列与其他谱子空间的严格间隔下界 `gap`。
3. 每列的子空间偏离上界 `R/(gap*L)` 不超过原认证使用的 `1e-4`。
4. 精确计算候选 Gram 矩阵，即向量间内积矩阵。严格对角占优给出其最小特征值正下界 `delta`。再要求 `(sum(R/gap))² < delta`，保证候选投影到已计数谱子空间后仍线性独立。计数维数相等时，才能证明该组覆盖完整，不能由重复或错误向量凑数。

另外要求每个候选包含半径不超过 `4096*n*2^-52*max(abs(theta), 2^-1022)`。这是新增的保守认证要求，用于阻止一个无关巨大矩阵项使错误的小特征值通过缩放残差。既有残差、正交性、绝对残差阈值均保持不变。

最近 `k` 目标要求恰有 `k` 个候选，且按原目标排序。在包含全部候选区间的原目标对称邻域内，精确计数也必须恰为 `k`，从而排除漏掉更近模式和边界重数。当前对扩展后多于 `k` 列的 `cluster_complete` 集合保守拒绝；不能把一组近邻根自动认作精确重根。区间目标先独立算出整个半开区间的数量，再确认每组候选区间均完整位于其中。空区间可以仅凭独立计数认证；无法解析的端点或邻近簇仍保持 `UNVERIFIED`。

## 明确预算

| 项目 | 默认上限 |
|---|---:|
| 矩阵阶数 | 64 |
| 输入存储项数 | 4096 |
| 消元中同时保存的稀疏项数 | 4096 |
| 保存的有理分子、分母位长 | 16384 bit |
| Schur、残差行或 Gram 项更新数 | 2000000 |
| 独立惯性求值次数 | 256 |
| 一次认证总耗时 | 5 秒，更新之间协作检查 |

位长限制检查保存的结果及消元系数，单次有界算术表达式的临时值可能更大；不是实时系统的硬截止承诺。进程资源与取消检查仍独立执行。矩阵超过阶数预算、填充或位长增长、计数次数或时间耗尽、仅近似厄密以及证明链无法闭合时，均保留候选并返回 `UNVERIFIED` 和具体原因。不会为了通过认证放宽阈值或把超限认作零。

结果报告 `certification_source=bounded_exact_rational_inertia_v1`、实际计数、角度界、拒绝原因和 `certification_arithmetic` 预算/成本。最终产物导出后再次重算，保存的 `validation.json` 不作为独立真值；清单同时绑定原输入和全部产物哈希。
