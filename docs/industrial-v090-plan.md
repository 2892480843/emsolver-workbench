# 工业验收五项继续实施计划

**目标：** 推进完整工业矩阵求解、目标完整性、独立参考、工程来源审查及成功条件下的性能实证。保留所有历史失败，不降低既有门槛，不把软件实现或合成通过当作工业通过。

**架构：** 生产候选求解、独立数值参考和严格目标证明分别执行，参考不进入候选工作进程。工程来源文献与独立机构审查分开登记。性能比较只有在两端数值与目标条件成立后生成。

**环境：** 已确认 macOS ARM64、16GiB物理内存；仅使用本机及合法公开资源。既有v0.8源码、任务、矩阵和交付包保留。所有大规模计算由主进程统一调度，受实际内存、磁盘、时间与宿主余量保护。

## 方案与取舍

| 路线 | 所解决的问题 | 选择条件 |
|---|---|---|
| 有界分块/多层近似逆 | 不完全消元零主元与修正方程有效性 | 在独立实复不定训练/保留集合上检查原方程残差，不能仅凭分解成功选择 |
| 独立稀疏直接法与磁盘因子 | 获取真实矩阵候选参考，避免继续依赖同一种ILU | 先验证已安装后端的外存控制与资源边界；只做有界试验，浮点结果不当作严格完整性证书 |
| 经验证的双移位惯性夹逼 | 原圆盘法不适用时证明目标端点计数 | 必须取得可核验分解并严格控制原矩阵分解残差；普通浮点惯性不够 |
| 原作者资料与其他公开工程模型 | 补物理来源、几何/材料/边界及已发表对照 | 权属与可获取内容逐项核对；不伪造缺失网格、质量矩阵、频率映射或审签 |

## 可验证任务

- [x] 复核原始失败、当前输入哈希及资源；分解失败不推出原矩阵奇异。
- [x] 独立检索原作者模型/参考/许可，登记已知资料、缺失资料和来源可信度。
- [x] 对通用稳定求解方案做独立小规模诊断，固定策略后再运行完整工业输入。
- [x] 验证独立外存求解器的API、硬限制、实际残差与运行产物；不绕过当前软件认证状态。
- [x] 实现并反例验证可行的严格计数原型，明确向工业规模推广仍需的接口与资源。
- [x] 仅在成功条件满足后形成公平性能对照；否则记录未满足的前置条件。
- [ ] 更新五项逐项证据和软件登记，通过回归与独立审查后交付。

资料检索与丢弃式研究脚本采用来源交叉核对、固定协议和独立对照验证；生产行为变更采用先失败测试再实现。技术上无法补出的外部机构审查保持未验证，不能通过自行签发回执消除。

## 当前实测结果

正式系统原GSM任务已数值合格2模式（约84秒），隔离ARPACK参考数值比较通过。完整原矩阵的严格残差二范数包围证明至少存在2个不同谱点，目标无遗漏仍未证明；图符号分析已量化1858亿次标量分解工作与单组显式因子2.74GiB成本。生产831项、实际OOC67项、Metal9项、前端65项通过；Mac冷安装和LinuxAMD64冷容器通过，新旧原始条款66项不变、历史18份发布归档不变。最终交付包待最后封装核对。
