# PRD 逐项验收登记（v0.9.0）

> **参赛交付口径更新（2026-10-16）**：下文为历史软件路径实现登记。当前源码增加团队集群能力后，参赛材料对 F34、F45、F48、F62 采用更保守的合并交付判定：62 项声明范围内闭环、4 项部分实现／条件未闭环。完整原条款和差异见[本次功能完成度声明](submission/功能完成度与未完成项.md)。历史 `implemented` 不代表所有平台或工业条件已完成。

**65项已实现、F48一项有条件，共66项。** 本轮增加显式磁盘外对称不定分解、完整真实微波矩阵的数值合格候选和隔离ARPACK参考。严格目标完整性仍未完成，不能据数值收敛、合成或教学算例声明全部工业要求完成。

原始条款完整保留在 `feature-coverage.json` 的 `prd_requirement` 中；本轮没有删除条款或降低验收门槛。`implemented` 指所列支持范围的软件行为及失败处理已实现，`conditional` 指尚未满足外部实证条件；两者不等于官方成绩或模型物理正确性。
