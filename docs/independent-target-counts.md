# 有间隔大矩阵的独立目标计数

`emsolver.numerics.independent_counts.certify_gapped` 为超过原有 64 阶精确消元预算的部分厄密矩阵提供独立目标认证。**支持条件是能够用原矩阵的行谱范围严格分离目标；不是任意大规模稀疏矩阵的完整性证明。** 十万阶正向测试是合成夹具，不构成真实工业器件验收证据。

## 为什么没有把 MUMPS 惯性直接作为严格证明

惯性指矩阵负、零、正特征值的数量，移位后可用于区间计数。[PETSc 的 `MatGetInertia` 文档](https://petsc.org/release/manualpages/Mat/MatGetInertia/) 要求已进行对应的对称分解，现有 SLEPc 候选后端使用的非对称 LU 分解不能直接替代。

[MUMPS 官方说明](https://www.mumps-solver.org/index.php?page=faq) 指出并行根节点使用 ScaLAPACK 时可能只得到负惯性的下界，需要相应配置避免该路径；[PETSc 的 MUMPS 实现](https://petsc.org/main/src/mat/impls/aij/mpi/mumps/impl/imumps.c.html) 还明确拒绝将复杂厄密矩阵当作复杂对称 Cholesky 输入。浮点主元、零主元阈值及没有严格误差界的符号计数不能自动升级为精确谱证书。本次没有增加这样的“通过”路径，也没有对真实大矩阵进行额外 MUMPS 分解。

## 认证依据与实现

对实际输入中保存的 IEEE 浮点数，使用它们所代表的精确二进制有理数。矩阵必须逐项严格厄密；不采用近似相等、不静默对称化，不删除很小的系数。

第 \(i\) 行的中心为实对角项 \(d_i\)，半径使用保守上界

\[
R_i=\sum_{j\ne i}(|\Re a_{ij}|+|\Im a_{ij}|).
\]

其大小不小于通常的复数模长行和，且可以完全精确计算。Gershgorin 定理（盖尔圆定理，用每行系数给出特征值所在范围）保证全部特征值位于这些扩大圆盘的并集。若若干圆盘与其余圆盘严格分离，则该并集内的特征值数量等于圆盘数，按重数计。该结论可从对角矩阵到原矩阵的连续变化证明，扩大半径仍保持保守性。[UAB 讲义，第 15.27 节](https://people.cas.uab.edu/~mosya/teaching/660new3.pdf)、[Rutgers 讲义，定理 19](https://sites.math.rutgers.edu/~falk/math574/lecture7.pdf) 给出了分离计数结论。

`GappedCountOracle.inertia(s)` 仅在每个实谱范围严格落在 \(s\) 左右时返回负、正计数。半径为零且中心恰为 \(s\) 的孤立坐标行，可以贡献精确零重数；其他圆盘碰到或跨过 \(s\) 均拒绝。由严格小于端点的数量之差得到半开区间 `[lower, upper)` 的计数。

### 精确带权圆盘扩展

`certify_weighted` 使用正对角相似变换（改变坐标尺度但保留全部特征值）扩大可证明的矩阵范围。设 \(D=\operatorname{diag}(w_i)\)，所有 \(w_i>0\)，则 \(B=D^{-1}AD\) 的中心仍为 \(a_{ii}\)，扩大半径为

\[
R_i^{(w)}=\sum_{j\ne i}(|\Re a_{ij}|+|\Im a_{ij}|)\,w_j/w_i.
\]

\(B\) 一般不再厄密，但与原矩阵具有完全相同的特征值；圆盘包含和分离计数定理适用于一般矩阵。原矩阵仍必须严格厄密。**候选残差、向量内积和子空间证明始终使用原矩阵 \(A\)，不能对 \(B\) 误用厄密残差界。** 相似变换保谱与一般矩阵圆盘定理见 [Saad, CSCI 5304 讲义, 2024, Lecture 12 第 7、12 页](https://www-users.cse.umn.edu/~saad/csci5304_F24/FILES/LecN12.pdf)；对 \(D^{-1}AD\) 的逐项系数应用该定理即可推得上述带权半径。圆盘分离计数仍使用前述 UAB 与 Rutgers 定理。

权重策略固定为 `row_component_inverse_sqrt_power2_v1`，只读取原矩阵，完全独立于候选值、候选向量和参考答案：

1. 每行取 \(m_i=\max_j\{|\Re a_{ij}|,|\Im a_{ij}|\}\)，包含对角项。
2. 非零行用 `frexp(m_i)` 得到整数 \(e_i\)，满足 \(2^{e_i-1}\le m_i<2^{e_i}\)；令 \(s_i=-\lfloor(e_i-1)/2\rfloor\)，\(w_i=2^{s_i}\)。全零行令 \(s_i=0\)。这是一种确定性尺度启发式，不保证产生最佳圆盘。
3. 保存小端 `int16` 指数，半径中直接以精确有理数计算 \(2^{s_j-s_i}\)。不生成浮点权重，也不构造缩放后的稀疏矩阵，因此不会因权重比例溢出或下溢丢失非零系数。

指数预扫描逐项计入运算预算，每个切片最多 65,536 个存储项，切片前后检查时间与取消。若必要的 `n+nnz` 次扫描已超运算预算，在全量有限性扫描、稀疏厄密比较和指数分配前直接拒绝。带权路径额外限制至 1,000,000 阶，指数数组最多 2,000,000 字节；有限 IEEE 输入的指数范围为 `[-511, 537]`。返回 `weight_policy`、`weight_exponent_min/max` 和小端指数字节的 `weight_exponents_sha256`，不向 JSON 输出逐行权重。哈希用于审计策略输出，原矩阵身份仍由既有制品绑定保证。

例如实数或复数星形矩阵，对角为 `[1,4,4,4,4]`，中心与各叶的耦合模长为 `11/16`：均匀圆盘不能严格分离最近一个特征值；此策略得到权重 `[1,1/2,1/2,1/2,1/2]`，能够严格分离并通过同一候选证明。此例和 81 阶星形测试均为合成夹具，**不构成 GSM 矩阵已求解、已认证或工业物理模型已验收的证据**。

权重不能改变对角中心；若 \(a_{ii}=\sigma\) 且有非零非对角项，对应圆盘仍覆盖目标位移。因此它不能替代通用的严格惯性证明，且可能比均匀策略更差。默认 `certify_gapped` 继续使用均匀策略，调用方可在明确的圆盘几何拒绝后单独尝试带权路径；不得重试无效输入、候选错误或已耗尽的父级资源截止。两次调用分别受自身预算及同一父级工作进程的硬截止约束。

### 最近 k 个模式

先完全独立于候选结果，从原矩阵挑选相对原目标位移的最大径向范围最小的 `k` 个行圆盘。设这组圆盘的最远范围为 \(r_{in}\)，其余圆盘与目标的最近范围为 \(r_{out}\)。只有 \(r_{in}<r_{out}\) 时，才使用两者中间的半径建立对称谱窗，并在两个端点独立计数，要求恰有 `k` 个特征值。

因此窗内全部模式一定比窗外模式更接近原目标。位移处若已有超过 `k` 个圆盘覆盖，则本方法不能证明固定 `k` 的分离，可提前保守拒绝。不能通过只截取部分重根或修改目标来获得通过。

### 区间全模式

每个行圆盘必须能够严格归入区间内部、左侧或右侧；跨越区间边界时拒绝。半径为零的精确端点坐标按半开语义处理。只有独立计数确为零时，空结果才可取得目标认证。

### 候选值、重数与子空间

仅有整个目标窗的正确数量和候选向量张成维数仍然不够。例如 `diag(1,2,100)` 的候选值可以伪装成 `[1,1]`，两个几乎平行向量仍张成前两个坐标；不能因此声称值 `2` 已正确返回。

实现额外执行：

1. 精确计算原问题残差 \(r_j=A x_j-\theta_j x_j\)。令 \(U_j\) 为残差实、虚分量绝对值之和，\(L_j\) 为向量分量实部、虚部绝对值的最大值，则 \([\theta_j-U_j/L_j,\theta_j+U_j/L_j]\) 至少包含一个真实特征值。这采用厄密残差谱位置界；[Cornell 课程说明](https://www.cs.cornell.edu/courses/cs6210/2025fa/lec/2025-12-01.html) 也解释了该基本联系。
2. 保留原有严格值范围限制：半径不能超过 `4096*n*2^-52*max(abs(theta), 2^-1022)`，避免无关巨大系数授权错误的小特征值。
3. 合并重叠的候选包含区间。在相邻组之间建立中点分隔；每个分隔必须由独立圆盘计数证明无根，每组对应分区的根数必须等于候选列数。无法证明分隔的圆盘间隔时拒绝。
4. 含多个候选列的组，还必须在其**紧的残差包含区间并集**内独立计得相同重数。不能借整个目标大窗口的数量替代本组重数。一般非对角重根若无法满足这一严格条件，继续保持未认证。
5. 对每组和整个目标，计算精确 Gram 矩阵（向量相互内积），严格对角占优给出最小特征值下界 \(\delta>0\)。根据与组外谱的严格距离 \(g_j\)，定义泄漏上界 \(B=\sum_j U_j/g_j\)。要求 \(B^2<\delta\)，保证投影后的列仍线性独立；进一步要求 \(B^2/\delta\le10^{-8}\)，使整个候选列空间的最大主角正弦不超过 `1e-4`。

最后一个条件针对整个列空间，而不只是每列向量的夹角。它会拒绝几乎相关的向量通过消去放大微小错误方向的情况。整数向上平方根与向上舍入用于展示角度上界，避免极小正界转为浮点零。

## 接口与预算

```python
from emsolver.numerics.independent_counts import certify_gapped, certify_weighted, GappedCountBudget

proof = certify_gapped(
    canonical_csr_matrix, eigenvalues_numpy_array, eigenvectors_numpy_array,
    resolved_config,
    budget=GappedCountBudget(),
    check=runtime.check,
)

# Optional second proof with a separately bounded, source-derived weight policy.
weighted_proof = certify_weighted(
    canonical_csr_matrix, eigenvalues_numpy_array, eigenvectors_numpy_array,
    resolved_config, budget=GappedCountBudget(), check=runtime.check,
)
```

输入必须是规范 CSR（压缩行稀疏格式），支持 `float32`、`float64`、`complex64`、`complex128`；候选数组也使用这些类型。实现检查真实索引顺序与唯一性，不只信任可被覆盖的 SciPy 缓存标志。矩阵转换、候选有限性扫描与稀疏列格式转换前先检查对应预算。取消异常向调用方传播。

| 项目 | 默认上限 |
|---|---:|
| 阶数 | 1,000,000 |
| 输入非零存储项 | 30,000,000 |
| 候选模式 | 16 |
| 候选向量元素 | 2,000,000 |
| 精确运算计费次数 | 5,000,000 |
| 保存的分数分子、分母位长 | 16,384 bit |
| 独立惯性端点调用 | 32 |
| 协作式时间预算 | 5 秒 |

输入预算允许尝试大矩阵，不保证其圆盘分离、计算时间或候选数量一定满足证明条件。直接 Python 调用的时间检查不是实时硬中断；服务端使用既有受限验证工作进程提供独立内存与截止保护。原矩阵始终稀疏；只形成现有候选向量、稀疏格式转换与小型精确内积，不执行全矩阵稠密化、浮点分解或特征值求解。

返回值兼容原有认证字段，均匀来源为 `exact_dyadic_gapped_gershgorin_v1`，带权来源为 `exact_dyadic_weighted_gershgorin_v1`。拒绝时为 `UNVERIFIED` 并给出 `certification_limit`；数值残差是否合格仍由既有数值验证单独判断。两种方法共用全部分组重数、候选值范围、投影秩和整体子空间角检查。该方法只处理固定 `k` 的严格分离窗口；不能证明的边界簇不自动扩展或宣称完整。
