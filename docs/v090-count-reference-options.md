# v0.9 独立谱计数与参考结果研究

本轮形成了一个可运行、可反例检验的**严格惯性夹逼原型**。惯性是矩阵负、零、正特征值的个数；对 `A-sI` 数负特征值，就能知道原矩阵有多少特征值小于端点 `s`。原型已覆盖现有行圆盘方法不能证明的连通带状矩阵，但**没有在 GSM 工业矩阵上运行，也没有接入生产认证，更没有补齐工业验收**。

本机已确认是 macOS / Darwin arm64。本页的严格惯性原型只在独立构造的小型矩阵上验证，没有对完整 GSM 执行严格数值分解。[v0.8 试验记录](evidence/v080-industrial-experiment.json) 作为历史失败证据保留；v0.9 已另外完成完整工业图符号分析、数值求解及原矩阵候选严格包围。最新证明进展与仍未闭合的完整性边界见 [v0.9 工业谱证明进展](v090-spectral-proof-progress.md)，不能再把 v0.8 的求解失败当成当前数值状态。

## 方案选择

| 路线 | 可以证明什么 | 当前限制与取舍 |
|---|---|---|
| 精确有理消元 | 对保存的浮点系数代表的精确矩阵计算惯性 | 现有生产默认最多 64 阶；稀疏消元的填充与分数位长可能迅速增长。 |
| 普通 / 加权 Gershgorin 行圆盘 | 圆盘分离时证明谱计数 | 现有 GSM 普通圆盘记录为 `too_many_disks_cover_target`；固定加权方法的默认操作预算不足以完整扫描 21758924 项。提高预算不保证圆盘可以分离。 |
| MUMPS / SLEPc 浮点惯性 | 提供不同数值流程的计数与参考交叉检查 | 浮点主元计数本身不包含对原存储矩阵的严格误差证明，不能仅因两次结果一致就设为 `CERTIFIED`。 |
| **双移位 LDL* 分解 + 严格残差夹逼** | 对每个已闭合的端点证明精确惯性和谱间隙下界 | 选择为研究原型。无需完整逆矩阵；仍需要因子显式导出、填充和乘积成本预估，以及适合大规模的严谨算术。 |
| 分块 / 区域分解计数 | 若严格证明分块耦合误差小于间隙，可组合计数 | 不能删除跨块耦合后直接加各块的惯性。GSM 是连通矩阵，任取小块的成功不证明完整矩阵通过。 |
| 随机迹估计、轮廓积分秩估计 | 可辅助定位谱区间或发现异常 | 概率估计和数值秩阈值不是本系统所要求的确定性完整性证明。 |

## 证明判据

`LDL*` 是把厄密矩阵分为单位下三角矩阵 `L`、由一阶或二阶小块构成的 `D` 及 `L` 的共轭转置；它能通过 `D` 的小块符号计数获得分解乘积的惯性。这里不把浮点因子当成原矩阵的精确分解。

令 `H=A-sI`，选定严格正的有理数 `eta`。分别取得以下两个**不可信提供方**给出的浮点因子与置换：

\[
B_- = L_-D_-L_-^*,\qquad B_+ = L_+D_+L_+^*.
\]

验证器重新读取原系数，精确计算

\[
E_-=P_-(H-\eta I)P_-^*-B_-,\qquad
E_+=P_+(H+\eta I)P_+^*-B_+.
\]

它不读取提供方声称的残差、惯性或特征值。采用

\[
\delta_\pm=\max_i\sum_j(|\Re E_{\pm,ij}|+|\Im E_{\pm,ij}|)
\]

作为二范数的保守上界；因为残差是厄密矩阵，其一范数等于无穷范数，故 `||E||2 <= ||E||infinity <= delta`。全部运算把 IEEE 保存值解释为精确高斯有理数，即实部、虚部都是精确有理数。

只在下列条件全部满足时返回端点证明：

1. 原矩阵与两份 `D` 都精确厄密，`L` 确为可逆单位下三角矩阵，置换合法，`D` 只有互不相交的一阶或二阶块。
2. 两份 `D` 的精确惯性相同，且零特征值个数均为零，记为 `(m,0,n-m)`。
3. `delta_minus < eta` 且 `delta_plus < eta`。

由合同不变性，`B_minus` 和 `B_plus` 各有 `m` 个负特征值。将厄密特征值扰动界分别用于两边，得到 `H` 的第 `m` 个特征值严格小于 `-(eta-delta_plus)`，第 `m+1` 个严格大于 `eta-delta_minus`；端点 `m=0` 或 `m=n` 只需相应一侧。因此 `H` 的惯性恰为 `(m,0,n-m)`，且距零的最小距离至少为 `eta-max(delta_minus,delta_plus)>0`。

该判据与 [Rump, 1999, Section 4](https://www.tuhh.de/ti3/paper/rump/Ru99d.pdf) 的不定对称双移位验证一致；厄密扰动界另由 [Cornell, 2024, Eigenvalue perturbation bounds](https://www.cs.cornell.edu/courses/cs4220/2024sp/Perturbation.pdf) 和 [Hermitian perturbation paper, 2018, Theorem 1.1](https://link.springer.com/article/10.1186/s13660-018-1749-0) 交叉核对。上面的具体高斯有理数实现、边界拒绝和资源预算是项目研究实现，不是第三方软件提供的证书。

## 原型的数据结构与资源控制

代码位于 `artifacts/v090-count-reference-research/verified_inertia_sandwich.py`，没有修改 `emsolver/`。输入是完整原矩阵的 CSR（按行压缩的稀疏数组）、置换数组及两组显式 `L`、`D`。原型最多 4096 阶，不把这个上限描述为可直接支持工业规模。

验证每一行时，先形成该行 `LD`，通过 `L` 的稀疏列索引累加所需乘积，减去原矩阵被置换的该行，求严格残差行和后丢弃。不会形成整个 `LDL*`、整个残差矩阵或原矩阵的稠密副本。原型会在预算内把输入和因子转为有理数行结构，所以**行流式乘积不等于全部输入零复制**。

| 预算 | 原型默认上限 |
|---|---:|
| 阶数 | 4096 |
| 原输入与两份 `L/D` 的总存储项 | 200000 |
| 计费算术 / 校验更新 | 2000000 |
| 单行同时保存的项 | 4096 |
| 分子、分母位长 | 4096 bit |
| 一次夹逼验证总耗时 | 10 秒，算术步骤之间协作检查 |

原型还设置不可由调用方随意突破的硬上限。取消异常向外传播，时间、位长、行填充、存储或操作预算不足均返回 `UNVERIFIED` 和原因。这些协作检查不能替代将来生产进程的硬内存、时间和磁盘监督。

## 可复现实证

```bash
.venv-emsolver/bin/python -m pytest artifacts/v090-count-reference-research/test_verified_inertia_sandwich.py -q
```

观察到缺少实现的失败基线，随后 **26 项测试通过**。独立审查发现原输入行预算只在读完整行后检查；新增反例先复现了 `max_row_entries=1` 时仍读取 64 项的问题，再改为每次保存新项立即检查，现最多保存第二项即拒绝。测试包括实数和复数的独立 LAPACK 因子、二阶主元、非恒等置换、精确零根、端点间隙不足、因子损坏、非厄密输入、非法块结构、非法置换、全部预算及取消。另有 40 个留出随机案例，向不可信因子加入从很小到破坏性的扰动，所有接受结果都与独立小型特征值参考核对；拒绝不会当成成功。

| 合成算例 | 阶数 / 存储项 | 结果 | 严格惯性 | 最高单行项数 | 计费更新 |

第二类矩阵由独立定义的精确二进制 `L D L*` 构造，`D` 的正负交错给出独立预期惯性；普通圆盘和现有固定加权圆盘在端点零都返回 `disk_crosses_count_point`。257 阶测试在提供因子后禁止验证代码调用稠密转换、特征值求解、分解及稀疏矩阵乘法，仍通过逐行证明。这说明原型扩展了这一小类矩阵的可证明范围，**不说明 GSM 的填充、间隙或成本也满足条件**。

记录中的约 0.04 / 0.34 秒只属于低填充合成验证器耗时，未计工业分解，也不构成工业速度、加速比或资源达标证据。

## MUMPS / PETSc / SLEPc 的实际接入边界

当前本地交付后端绑定 PETSc 3.18.5 / SLEPc 3.18.2。为避免拿最新页面行为代替本地版本，本轮同时核对了固定版本源码：

- [PETSc v3.18.5 MUMPS adapter](https://raw.githubusercontent.com/petsc/petsc/v3.18.5/src/mat/impls/aij/mpi/mumps/mumps.c)：实数 `MatGetInertia_SBAIJMUMPS` 读取 `INFOG(12)`；请求零数 / 正数要求 `ICNTL(24)=1`，并行惯性要求 `ICNTL(13)=1`。该实现的复数分支没有惯性回调。读取这些整数没有重算严格的原矩阵分解残差。
- [SLEPc v3.18.2 Krylov-Schur source](https://raw.githubusercontent.com/slepc/slepc/v3.18.2/src/eps/impls/krylov/krylovschur/krylovschur.c)：`EPSKrylovSchurGetInertias` 仅用于区间谱切片，可返回端点和内部移位的惯性；不是当前最近 `k` 求解器自动附带的精确证书。
- 最新 [PETSc MatGetInertia 文档](https://petsc.org/release/manualpages/Mat/MatGetInertia/) 与 [SLEPc 谱切片说明](https://slepc.upv.es/release/documentation/manual/st.html) 用于接口含义交叉核对，不据此声称本机已升级版本。

MUMPS 的内存外分解是低内存数值路线：`ICNTL(22)=1` 使用磁盘保存部分因子，`ICNTL(23)` 约束其内部工作内存；仍需单独限制容器、Python、PETSc 输入副本和磁盘。分析阶段预估不保证实际峰值，不能无监督试跑。控制项含义见 [MUMPS 5.8.2 官方用户指南](https://mumps-solver.org/doc/userguide_5.8.2.pdf)，项目实际版本另按固定的 5.5.1 手册与源码复核。v0.9 的工业数值试验由独立求解任务执行；本页讨论其严格因子证明缺口，数值试验成功不自动产生该证明。

最直接的开放因子接口候选是 [SuiteSparse LDL 官方用户指南](https://raw.githubusercontent.com/DrTimothyAldenDavis/SuiteSparse/dev/LDL/Doc/ldl_userguide.tex)，它显式输出 `L` 与 `D`，可先做符号分析。但其算法没有数值主元交换，仅对条件合适的不定矩阵适用；不能假定在 GSM 近零移位上稳定，也不能把它当作 MUMPS 稳健主元功能的等价替换。另一条路线是实现并审查 MUMPS 实际因子、缩放和置换的明确导出桥接；目前没有已验证可直接使用的桥接，不能把 `MatGetFactor()` 返回的后端对象等同于可遍历的公开 `L/D` 数组。

## 真正进入工业验收前的接入顺序

1. 在独立、未用于调参的中型连通实数 / 复数矩阵上验证因子提供方和导出协议，保留全部缩放、置换与一阶 / 二阶块。缩放若用于合同变换，必须同时变换完整 `A-sI`，不能把缩放后标准特征值当成原标准问题特征值。
2. 先根据因子稀疏结构计算乘积更新数上界、最大行填充和磁盘需求；成本超限先拒绝。逐行不保存全乘积能降低内存，不能消除乘积本身可能很大的工作量。
3. 将精确原型作为小型测试真值，开发按块、有严格外舍入的批量残差验证器，并验证实数 / 复数、极端尺度、下溢、溢出与线程环境。不能以普通 `float64` 稀疏乘积后随意加一个 epsilon 替代。
4. 每个端点执行双移位因子及独立验证；区间两端至少需要四次分解。最近 `k` 目标的完整性还要组合候选精确残差包围、分组重数、组外间隙和投影线性独立证明。端点计数通过本身不代表全部候选认证通过。
5. 候选参考采用不同数值流程独立运行，绑定原输入摘要、目标、原单位残差、工具版本、源码摘要和完整向量。候选工作进程不得读取参考。整个协议先冻结，再进行受监督的全 GSM 试验；失败保留原记录，不改阈值冒充通过。

如果原矩阵目标间隔小于可证明的分解残差，或因子填充超出本机资源，这条路线仍会拒绝。这是具体数学与资源缺口，需要更高精度、更好分解或更合适的计算资源，不能通过改验收状态解决。

## 独立数值方法与机构审查不是同一件事

当前 `emsolver/industrial.py` 将相关门禁明确分开：

| 门禁 | 现有依据 | 本轮原型能够增加什么 |
|---|---|---|
| `target_coverage` | 重新计算目标认证，且候选任务为 `SUCCEEDED` | 将来经集成后可提供一个严格端点计数部件；当前未接入。 |
| `reference_comparison` | 读取实际参考完整向量，比较特征值和重根子空间 | 可独立生成数值对照，但目前 GSM 没有合格候选和完整参考。 |
| `reference_provenance` | 候选自产答案拒绝；另需配置机构针对冻结绑定的回执 | 不可由“换一个算法”或“数学证明成立”自动代替机构来源审查。 |
| `physical_review` | 工程证据齐备并有配置机构审查回执 | 惯性证明不恢复缺失的几何、材料、边界、网格和频率关系。 |

HMAC（共享密钥认证码）证明的是配置机构的断言经过认证，不证明其物理内容正确，也不是公开可验证的数字签名。没有真实机构审查时，应保留 `NO_TRUSTED_ATTESTATION` / `TRUST_AUTHORITY_NOT_CONFIGURED`；不能自动创建一个自签机构或给生产档案填测试回执来取得工业通过。独立本地工具可以提供可复核数值证据，独立机构回执仍是当前验收协议中单独要求的外部证据。

现有 [GSM 原始归档记录](evidence/v060-public-industrial-dataset.json) 包含矩阵 `A` 和右端 `b`，未提供质量矩阵及经审核的频率关系。对其标准矩阵求谱可用于数值算法验证，但不能据此输出真实器件谐振频率。此研究不会改写现有矩阵范围与物理范围的区别。
