# 参赛功能完成度与未完成项声明

本登记保留原 PRD 的 F01-F66 共 66 项要求，不删除条款，不将第三方数值库实现计为项目自研。

**计算口径**：66 项等权；62 项在声明支持范围内闭环，占 93.94%；4 项部分实现／条件未闭环，占 6.06%；整项完全无实现为 0。部分项不计入闭环数。本比例不是代码覆盖率、工作量百分比、工业成功率或官方评分。

历史 `feature-coverage.json` 的 implemented 表示支持范围内的软件路径存在；本次参赛登记采用更保守的本地与集群合并交付口径。以下部分项含真实未实现子功能，不能把“0 项完全空白”解释为“无缺失”。

## 范围外扩展与尚未验证部署条件

下列扩展不加入原 66 项分母，也不把它们包装成已实现：账号密码／SSO 自助账户体系、S3 对象存储、多 API 副本高可用、远程 SLEPc/GPU、同一矩阵跨多节点联合求解均未实现；多台物理机器 HTTPS 与跨机器性能收益尚未验收。现有用户身份由独立令牌及项目成员角色授权，任务按节点整项分发。
