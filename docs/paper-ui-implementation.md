# 论文排版风界面实施记录

## 目标与依据

按用户提供的 `STYLEKIT_STYLE_REFERENCE / latex-paper` 改造现有13个工作区。采用白纸、墨黑、中文及西文衬线、蓝色交叉引用、居中文档头与摘要、编号章节/图/表、三线表和方角控件。现有求解、权限、数据与认证语义保留。

参考内部冲突按最后的禁止项处理：定理/提示环境使用浅底与横线，不使用单侧粗装饰边框；页面白底，不采用示例中的黑底黑字。蓝色只用于可点击链接，不用于状态或科学数据。字体使用本机已有衬线字体与可移植回退，不增加网络字体依赖。

## 架构与范围

- `web/src/style.css`：清理旧配色、阴影、圆角及装饰，保留已有布局契约。
- `web/src/paper.css`：集中维护配色与字体变量、论文排版、章节计数、响应式、打印和交互状态；在基础样式后加载。
- `web/src/ui.tsx` 与 `App.tsx`：文档头、目录导航、摘要、章节标题、真实版本信息、公式、表题及纯文字操作。
- 科学图组件：保留原始数据，改用灰阶/线型/点型区分，并提供图注。
- 工程与工业工作区：统一局部控件样式、选中状态和横向滚动表格。
