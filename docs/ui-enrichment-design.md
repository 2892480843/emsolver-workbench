# 工作台界面元素增强

## 目标与设计

保留用户指定的论文排版风，增强真实信息与操作层次。采用紧凑文档头、可跳转索引、实验快捷操作、全量任务状态图与已加载任务动态。图形始终对应真实数据并具有图注；不新增装饰图形、虚构进度或无来源统计。

纯增加留白与字体层次无法解决元素偏少；堆叠重复卡片会降低操作效率。本轮以数据摘要和上下文操作丰富页面，继续使用白纸、墨黑、衬线、灰阶、方角、横线与蓝色链接。

## 实施计划

- [x] 新建 OverviewInsights、独立概览模型及数据边界测试，使用服务端全量状态汇总与已加载任务记录。
- [x] 新建 PageOutline，读取真实二级标题，支持动态更新、编号跳转、键盘定位及展开完整目录。
- [x] 新建 WorkbenchActions，将输入、计算、运行和结果入口与实际选择状态、任务指标联系起来；说明草稿输入与运行输入的区别。
- [x] 整合总览的图表、动态、指标和任务表；压缩重复页头留白，统一新元素的响应式与打印规则。
- [x] 构建、模型回归、真实浏览器交互及多宽度验证，并检查业务实体内容保全。

## 数据与功能边界

- 全量任务分布只取 `WorkspaceSummary.job_status_counts`；不按当前已加载页推断总量。
- 动态与近期明细仅依据已加载任务，分页时显式提示；不称为全局审计记录。
- 草稿输入只取 `selectedMatrix`，选中任务状态与目标认证独立呈现；不把任务绑定输入或冻结配置冒认为草稿，部分结果不升级为认证通过。
- 所有快捷操作是现有页面跳转或显式状态筛选；不自动创建项目、任务、配置或工业认证。
- 继续保留13个工作区、已有权限与数据接口；无新增依赖，无数值模块或数据库修改。

## 验收

检查状态入口筛选、动态打开运行、本页索引的动态标题与焦点、全部目录展开及页面切换。检查桌面/平板/手机页面边界，保存日志、截图及内容摘要到 `artifacts/ui-enrichment-20261016/`。冻结历史发布产物保持原样。
