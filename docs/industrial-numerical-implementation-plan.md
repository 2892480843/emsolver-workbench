# 工业数值剩余项实施计划

**目标：** 改进完整工业原矩阵的稳定求解能力，并增加具有明确适用条件的独立目标完整性证据；保留无法认证的结论。

**架构：** ILU 预处理作为 JD 修正方程的独立组件接入，不改变原始问题和最终双精度验证。独立谱计数与候选计算分离，使用有界、可中止的精确算术证明；不读取参考答案选择算法。

环境：macOS ARM64，物理内存16GiB。原矩阵、历史任务和v0.6发布档案保留。

## 取舍

采用固定通用ILU和明确数学条件下的计数证明。完整直接LU仍可能超出当前可用内存，浮点分解的惯性数字也不直接作为严格证明。不存在把残差小、两个程序一致或人工声明自动写成完整性通过的路径。

## 证据要求

最终残差和目标保持原配置要求。预处理工作位移只影响近似逆，不能更换原目标。分解填充估计不是RSS上界；进程树仍须受实际资源守卫监督。教学／合成数据只能证明相应软件路径，不能替代真实微波器件数值验收。

## 已观察结论

本轮计划的软件、受控实验与交付步骤已完成，F48工业正向验收未完成。固定ILU在完整公开原矩阵上发生分解零主元；分离圆盘计数因覆盖目标的圆盘过多拒绝。具体预算与失败见`docs/evidence/v070-industrial-experiments.json`，不把本计划勾选作为工业通过证明。
