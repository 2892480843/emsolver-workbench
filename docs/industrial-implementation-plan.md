# 工业验收闭环实施计划

基线：v0.5.0；环境：macOS ARM64，16 GiB 物理内存。范围来自原参赛 PRD 的矩阵求解与工业证据链，不扩大成电磁 CAD 平台。

1. 保留现有数据、历史任务和发布档案，登记当前代码与数据库基线。
2. 经官方 HTTPS 来源取得未经修改的公开微波工业矩阵，记录原始包、矩阵摘要、出处与许可；下载和解压均设限。
3. 新增独立工业验收域：模型与任务绑定、物理假设、材料／边界／网格说明、独立参考与性能门槛，形成不可变档案和检查记录。
4. 提供项目权限下的创建、版本修订、逐项检查、查询和报告下载界面；备份恢复验证档案摘要与跨实体绑定。
5. 对实际工业矩阵执行资源预算内的数值实验；保留所有失败、超时和未认证结论，禁止原矩阵稠密化。
6. 测试权限、篡改、错误参考、缺失数据与正常路径；进行浏览器操作验证、数据保留检查，更新交付文档。

## 验收规则

- 数值残差合格、目标完整性、物理模型有效性、参考吻合和性能分别判定；缺少证据为 UNVERIFIED。
- 解析教学模型、用户声明、两个候选程序一致均不能单独证明真实工业正确性。
- 本机实验不代表官方保留集、原生 Linux 赛事硬件或所有工业器件通过。
- 历史 v0.5 档案不覆盖；本轮新增证据采用 v060 前缀，最终发布状态由实际测试决定。
